# RNF-016 — Tiempo de carga
## Identificación

| Campo |	Valor |
| ----------- | ----------- |
| ID |	RNF-016 |
| Nombre |	Tiempo de carga |
| Categoría |	Rendimiento |
| Prioridad |	Alta |
| Estado |	Pendiente |

# Requisitos
## RNF-016.1 — Carga inicial

La carga inicial no debe superar los 3 segundos.

## RNF-016.2 — Carga promedio

La carga promedio de las páginas debe ser inferior a 1.5 segundos.
