# Requisitos
## RNF-001.1 — Autenticación segura

El sistema debe requerir autenticación mediante usuario y contraseña.

## RNF-001.2 — Comunicación segura

Toda la comunicación entre el cliente y el servidor debe realizarse mediante HTTPS/SSL.
