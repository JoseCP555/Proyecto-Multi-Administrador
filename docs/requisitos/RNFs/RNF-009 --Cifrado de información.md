# RNF-009 — Cifrado de información
## Identificación

| Campo |	Valor |
| ----------- | ----------- |
| ID	| RNF-009 |
| Nombre |	Cifrado de información |
| Categoría |	Seguridad |
| Prioridad |	Crítica |
| Estado |	Pendiente |

# Requisitos
## RNF-009.1 — Protección de datos

La información sensible de los residentes debe cifrarse utilizando AES-256 o un estándar equivalente.
