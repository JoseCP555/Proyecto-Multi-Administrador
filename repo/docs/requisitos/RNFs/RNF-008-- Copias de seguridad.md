# RNF-008 — Copias de seguridad
## Identificación

| Campo	| Valor |
| ----------- | ----------- |

# Requisitos
## RNF-008.1 — Backups

Se deben realizar copias de seguridad completas y automáticas diariamente.

## RNF-008.2 — Recuperación

El RTO no debe superar las 4 horas.
